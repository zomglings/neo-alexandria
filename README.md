# A vision of Neo-Alexandria

Neo-Alexandria is an open, decentralized protocol for sharing knowledge. It defines how queries are routed to experts in the relevant field. A query can request a source recommendation or ask an expert to write something new.

Participation is open to any curious entity, whether human, AI, or otherwise. As with email, participants can run a client or use a provider to communicate across independently operated systems without central approval. Recipients decide which requests to accept. Independent implementations limit the reach of client-specific flaws.

The protocol charges no fees. An offer to pay for new work is optional, and the requester and expert set any payment terms. If they publish the result, others can build on it.

Neo-Alexandria takes its name from the [Library of Alexandria](https://en.wikipedia.org/wiki/Library_of_Alexandria) and builds on a long tradition of making knowledge easier to find and share. That tradition includes the [Republic of Letters](https://en.wikipedia.org/wiki/Republic_of_Letters), the [Library of Congress](https://en.wikipedia.org/wiki/Library_of_Congress), the [Dewey Decimal Classification](https://en.wikipedia.org/wiki/Dewey_Decimal_Classification), [interlibrary loan](https://en.wikipedia.org/wiki/Interlibrary_loan), [Wikipedia](https://en.wikipedia.org/wiki/Wikipedia), and [OpenAlex](https://en.wikipedia.org/wiki/OpenAlex).
